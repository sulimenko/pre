# Partner Finance — Pre-IPO Landing (Vue 3)

Одностраничный сайт Partner Finance, перенесённый с `landing-a-v3.html` на Vue 3 без изменения визуальной концепции.

## Запуск

Из папки проекта:

    cd ~/MYJob/pre
    npm install
    npm start

Vite откроет браузер на http://127.0.0.1:5178/ и будет обновлять Vue/CSS/JS через HMR.
Остановить сервер: Ctrl+C. Команда запуска существует только в package.json проекта.

## Проверка сборки

```sh
npm run build
npm run preview
```

## Архитектура

- `src/App.vue` — композиция разделов и управление двумя модальными окнами.
- `src/components/` — разделы страницы и интерактивные модальные окна.
- `src/data/` — единый источник данных о компаниях, котировках демонстрационного терминала и слайдах.
- `src/composables/useLandingMotion.js` — GSAP, ScrollTrigger, Lenis и логика кинематографической сцены.
- `src/styles.css` — прежние глобальные стили, без визуальных изменений (только пути к фоновым изображениям).
- `public/assets/` — копии исходных ресурсов для Vite.
- `landing-a-v3.html` и `assets/` — нетронутый исходник для сравнения.

Форма заявки, как и в исходном HTML, пока демонстрационная: переход к экрану успеха не отправляет данные на сервер. График терминала содержит случайно сгенерированные демонстрационные свечи.
